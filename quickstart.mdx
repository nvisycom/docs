This guide takes you from an API token to a redacted document.

## Prerequisites

- An Nvisy account, or a [self-hosted deployment](/deployment/on-premise/getting-started)
- An API token from **API Tokens** in your account settings
- A workspace — create one in the app, or with `POST /workspaces/`

<Tip>
  Export your token so the examples below can pick it up:
  `export NVISY_API_TOKEN="..."`
</Tip>

## Install an SDK

<CodeGroup>

```bash TypeScript
npm install @nvisy/sdk
```

```bash Python
pip install nvisy-sdk
```

```toml Rust
# Cargo.toml
nvisy-sdk = "0.1"
```

</CodeGroup>

The TypeScript SDK has full API coverage and is the reference implementation.
The Python and Rust SDKs currently provide configured HTTP clients.

## Verify Your Connection

<CodeGroup>

```typescript TypeScript
import { Nvisy } from "@nvisy/sdk";

const client = new Nvisy({ apiToken: process.env.NVISY_API_TOKEN! });

const workspaces = await client.workspaces.listWorkspaces();
console.log(workspaces.items.map((workspace) => workspace.slug));
```

```bash cURL
curl https://api.nvisy.com/workspaces/ \
  -H "Authorization: Bearer $NVISY_API_TOKEN"
```

</CodeGroup>

## Redact a Document

Redaction is deliberately two-phase: a run first **detects** sensitive data,
and nothing is modified until you **apply** redactions.

<Steps>
  <Step title="Upload a file">
    ```typescript
    import { readFile } from "node:fs/promises";

    const workspaceSlug = "acme";
    const bytes = await readFile("./contract.pdf");

    const [file] = await client.files.uploadFiles(
      workspaceSlug,
      new File([bytes], "contract.pdf", { type: "application/pdf" }),
    );
    ```
  </Step>

  <Step title="Start a detection run">
    ```typescript
    let run = await client.runs.createRun(workspaceSlug, "default", {
      fileId: file.id,
    });
    ```

    Runs move through `queued` → `analyzing` → `analyzed`.
  </Step>

  <Step title="Wait for detection to finish">
    ```typescript
    while (run.status === "queued" || run.status === "analyzing") {
      await new Promise((resolve) => setTimeout(resolve, 2000));
      run = await client.runs.getRun(workspaceSlug, run.id);
    }
    ```
  </Step>

  <Step title="Review what was found">
    ```typescript
    const audit = await client.runs.getDetections(workspaceSlug, run.id);
    console.log(`${audit.parts.length} parts analyzed`);
    ```
  </Step>

  <Step title="Apply redactions">
    ```typescript
    const completed = await client.runs.redact(workspaceSlug, run.id);
    console.log(completed.status, completed.outputFileId);
    ```
  </Step>

  <Step title="Download the result">
    ```typescript
    import { writeFile } from "node:fs/promises";

    const response = await client.files.downloadFile(
      workspaceSlug,
      completed.outputFileId!,
    );

    await writeFile(
      "./contract-redacted.pdf",
      Buffer.from(await response.arrayBuffer()),
    );
    ```
  </Step>
</Steps>
