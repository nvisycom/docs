This guide takes you from an API token to a redacted document.

## Prerequisites

- An Nvisy account, or a [self-hosted deployment](/deployment/on-premise/getting-started)
- An API token from **API Tokens** in your account settings
- A workspace — create one in the app, or with `POST /workspaces`

<Tip>
  Export your token so the examples below can pick it up:
  `export NVISY_API_TOKEN="..."`
</Tip>

## Install an SDK

<CodeGroup>

```bash TypeScript
npm install @nvisy/sdk
```

```bash Python
pip install nvisy-sdk
```

```toml Rust
# Cargo.toml
nvisy-sdk = "0.1"
```

</CodeGroup>

The TypeScript SDK has full API coverage and is the reference implementation.
The Python and Rust SDKs currently provide configured HTTP clients.

## Verify Your Connection

<CodeGroup>

```typescript TypeScript
import { Nvisy } from "@nvisy/sdk";

const client = new Nvisy({ apiToken: process.env.NVISY_API_TOKEN! });

const workspaces = await client.workspaces.listWorkspaces();
console.table(
  workspaces.items.map(({ id, handle }) => ({ id, handle })),
);
```

```bash cURL
curl https://api.nvisy.com/workspaces \
  -H "Authorization: Bearer $NVISY_API_TOKEN"
```

</CodeGroup>

<Note>
  Workspaces, documents, pipelines, and detections are all addressed by `id`.
  A workspace's `handle` is display-only — read the `id` from the listing above
  and use that in every call below.
</Note>

## Redact a Document

Redaction is deliberately two-phase: a detection first **finds** sensitive
data, and nothing is modified until you **redact**.

<Steps>
  <Step title="Pick a workspace and pipeline">
    ```typescript
    const { items: workspaces } = await client.workspaces.listWorkspaces();
    const workspaceId = workspaces[0].id;

    const { items: pipelines } = await client.pipelines.listPipelines(workspaceId);
    if (pipelines.length === 0) {
      throw new Error(
        `Workspace ${workspaceId} has no pipelines — create one first.`,
      );
    }
    const pipelineId = pipelines[0].id;
    ```

    A new workspace starts with no pipelines. Create one with
    `client.pipelines.createPipeline(workspaceId, ...)`, or skip pipelines
    entirely and run an
    [ad-hoc detection](/sdks/typescript/examples#ad-hoc-detection-without-a-pipeline)
    against a policy.
  </Step>

  <Step title="Upload a document">
    ```typescript
    import { readFile } from "node:fs/promises";

    const bytes = await readFile("./contract.pdf");

    const [document] = await client.documents.uploadDocuments(
      workspaceId,
      new File([bytes], "contract.pdf", { type: "application/pdf" }),
    );
    ```
  </Step>

  <Step title="Start a detection">
    ```typescript
    const detection = await client.detections.createDetection(
      workspaceId,
      pipelineId,
      { documentId: document.id },
    );
    ```

    Detections move through `pending` → `executing` → `complete`.
  </Step>

  <Step title="Wait for analysis to finish">
    Subscribe to the detection's event stream. It yields the current status
    immediately, then each transition, and ends once the detection settles.

    ```typescript
    let status = detection.status;

    for await (const event of client.detections.streamEvents(
      workspaceId,
      detection.id,
    )) {
      status = event.status;
    }

    if (status !== "complete") {
      throw new Error(`Detection ${detection.id} ended as ${status}`);
    }
    ```
  </Step>

  <Step title="Review what was found">
    ```typescript
    const audit = await client.detections.getAnalysis(workspaceId, detection.id);
    console.log(audit.report);
    ```
  </Step>

  <Step title="Apply redactions">
    ```typescript
    const redaction = await client.detections.createRedaction(
      workspaceId,
      detection.id,
      {},
    );

    console.log(redaction.id, redaction.outputDocumentId);
    ```

    Pass `{ edits }` instead of `{}` to layer reviewer changes over the
    analysis — suppressing a false positive, retagging an entity, or adding one
    the analysis missed.
  </Step>

  <Step title="Download the result">
    ```typescript
    import { writeFile } from "node:fs/promises";

    const response = await client.documents.downloadDocument(
      workspaceId,
      redaction.outputDocumentId!,
    );

    await writeFile(
      "./contract-redacted.pdf",
      Buffer.from(await response.arrayBuffer()),
    );
    ```
  </Step>
</Steps>

<Tip>
  To analyze a document without a saved pipeline, use
  `client.detections.createAdhocDetection(workspaceId, { documentId, policyIds })`
  and name the policies directly.
</Tip>
