## Overview

Nvisy's redaction workflow is designed to be simple, secure, and compliant. The four-step process ensures sensitive information is accurately identified and redacted while maintaining complete audit trails.

## Detailed Process

### 1. Document Upload

Upload documents through multiple channels:

- **REST API** - Direct HTTP uploads
- **SDKs** - JavaScript/TypeScript or Python
- **Web Interface** - Browser-based uploads
- **Batch Processing** - Multiple documents at once

### 2. AI-Powered Detection

Our AI engine analyzes documents for sensitive information:

- **PII Detection** - Names, addresses, SSN, phone numbers, email addresses
- **PHI Detection** - Medical record numbers, diagnoses, prescriptions, patient data
- **Financial Detection** - Credit card numbers, bank accounts, tax IDs
- **Custom Patterns** - Organization-specific sensitive data

Each detection includes:
- **Confidence score** (0-1) indicating certainty
- **Location** (page, coordinates) in the document
- **Type** classification
- **Context** surrounding text

### 3. Review Process

Before finalization, review detected items:

```json
{
  "detections": [
    {
      "id": "det_123",
      "type": "ssn",
      "confidence": 0.95,
      "text": "XXX-XX-XXXX",
      "page": 1,
      "coordinates": {"x": 100, "y": 200}
    }
  ]
}
```

Options during review:
- **Approve** - Confirm redaction
- **Reject** - Keep original text
- **Adjust** - Modify redaction area
- **Set threshold** - Filter by confidence score

### 5. Download & Audit

Receive redacted documents with:
- **Preserved formatting** - Original document structure maintained
- **Audit trail** - Complete record of all actions
- **Metadata** - Processing details and timestamps
- **Compliance reports** - For regulatory requirements

## Batch Processing

Process multiple documents efficiently:

```typescript
const results = await nvisy.documents.batchRedact({
  files: ['doc1.pdf', 'doc2.docx', 'doc3.xlsx'],
  detectionTypes: ['pii', 'phi'],
  parallel: true,
  maxConcurrent: 5
});
```

Benefits:
- **Parallel processing** - Handle multiple documents simultaneously
- **Progress tracking** - Monitor batch status in real-time
- **Error handling** - Individual document failures don't stop the batch
- **Consolidated reporting** - Single report for all documents

## Best Practices

### Setting Confidence Thresholds

- **High precision (0.9-1.0)** - Fewer false positives, may miss some items
- **Balanced (0.8-0.9)** - Recommended for most use cases
- **High recall (0.6-0.8)** - Catch more items, may include false positives

### Review Process

1. **Always review** high-value or legally sensitive documents
2. **Spot check** batch processed documents
3. **Adjust thresholds** based on your needs
4. **Use custom patterns** for organization-specific data

### Compliance

- **Maintain audit trails** for regulatory requirements
- **Set retention policies** for processed documents
- **Use webhooks** for automated compliance workflows
- **Export reports** for audit purposes
