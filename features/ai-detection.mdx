## Overview

Nvisy uses state-of-the-art AI and machine learning models to automatically identify sensitive information in documents with 99.9% accuracy. Our detection engine combines multiple techniques for comprehensive coverage.

### Protected Health Information (PHI)

HIPAA-compliant detection of health data:

- Medical record numbers (MRN)
- Patient identifiers
- Diagnoses and conditions
- Prescription information
- Provider names and NPIs
- Insurance policy numbers
- Lab results and values

### Financial Information

Detect financial data for PCI-DSS compliance:

- Credit card numbers (all major brands)
- Bank account numbers
- Routing numbers
- IBAN and SWIFT codes
- Tax identification numbers
- Investment account numbers

### Custom Patterns

Define organization-specific patterns:

```typescript
{
  customPatterns: [
    {
      name: 'employee_id',
      pattern: /EMP-\d{6}/g,
      description: 'Employee ID format'
    },
    {
      name: 'case_number',
      pattern: /CASE-[A-Z]{2}\d{8}/g,
      description: 'Legal case numbers'
    }
  ]
}
```

## Detection Algorithms

### Pattern Matching

Advanced regex-based detection with:
- **Context awareness** - Considers surrounding text
- **Format validation** - Verifies checksums (e.g., Luhn algorithm for credit cards)
- **Multi-language support** - Detects patterns across languages

### Machine Learning

Neural network models trained on:
- Millions of annotated documents
- Real-world PII, PHI, and financial data
- Industry-specific terminology
- Multiple document formats

### Named Entity Recognition (NER)

Identifies entities using:
- Contextual understanding
- Semantic analysis
- Relationship mapping
- Position-aware detection

## Confidence Scoring

Each detection includes a confidence score (0-1):

```json
{
  "detection": {
    "type": "ssn",
    "text": "XXX-XX-XXXX",
    "confidence": 0.95,
    "method": "pattern_matching"
  }
}
```

### Score Ranges

| Range | Interpretation | Action |
|-------|---------------|---------|
| 0.9-1.0 | Very high confidence | Auto-redact |
| 0.8-0.9 | High confidence | Redact with review |
| 0.7-0.8 | Medium confidence | Manual review |
| Less than 0.7 | Low confidence | Flag for review |

### Setting Thresholds

Configure minimum confidence for your use case:

```typescript
const result = await nvisy.documents.redact({
  file: './document.pdf',
  detectionTypes: ['pii'],
  confidenceThreshold: 0.85  // Only redact items >= 85% confidence
});
```

## Customization

### Custom Dictionaries

Add industry-specific terms:

```typescript
{
  customDictionaries: {
    medical: ['acetaminophen', 'metformin', ...],
    legal: ['plaintiff', 'defendant', ...],
    financial: ['amortization', 'derivative', ...]
  }

```

### Exclusion Lists

Prevent false positives:

```typescript
{
  exclusions: {
    names: ['Apple', 'Amazon', 'Meta'],  // Company names
    patterns: [/\d{3}-\d{2}-\d{4}/],     // Generic patterns to ignore
    contexts: ['copyright', 'trademark']  // Context-based exclusions
  }
}
```

## API Integration

### Basic Detection

```typescript
const analysis = await nvisy.detections.analyze({
  file: './document.pdf',
  detectionTypes: ['pii', 'phi']
});

analysis.detections.forEach(detection => {
  console.log(`${detection.type}: ${detection.confidence.toFixed(2)}`);
});
```

## Best Practices

### Choosing Detection Types

1. **Start broad** - Use `['pii', 'phi', 'financial']` initially
2. **Review results** - Check for false positives/negatives
3. **Refine** - Add custom patterns or adjust thresholds
4. **Test** - Validate on sample documents before production

### Setting Thresholds

- **Legal documents**: Use 0.9+ for high precision
- **Medical records**: Use 0.85-0.9 for balanced accuracy
- **General business**: Use 0.8-0.85 for broad coverage
- **Custom patterns**: Use 1.0 for exact matches

### Performance Optimization

- **Batch processing** - Process multiple documents together
- **Selective detection** - Only enable needed types
- **Parallel processing** - Use async/concurrent processing
- **Caching** - Reuse detection results when possible
