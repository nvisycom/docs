## Overview

Nvisy provides comprehensive audit trails for every document redaction, ensuring full traceability and compliance with regulatory requirements like GDPR, HIPAA, and SOC 2.

## Audit Trail Structure

Each audit entry contains:

```json
{
  "id": "audit_abc123",
  "timestamp": "2024-01-15T10:30:00Z",
  "action": "redaction_completed",
  "document_id": "doc_xyz789",
  "user": {
    "id": "user_123",
    "email": "user@example.com",
    "ip_address": "192.168.1.1"
  },
  "details": {
    "detections_found": 42,
    "items_redacted": 40,
    "items_rejected": 2,
    "confidence_threshold": 0.85,
    "processing_time_ms": 3500
  },
  "metadata": {
    "api_version": "v1",
    "sdk_version": "1.2.3",
    "environment": "production"
  }
}
```

## Action Types

### Document Lifecycle

| Action | Description |
|--------|-------------|
| `document_uploaded` | File uploaded to Nvisy |
| `analysis_started` | AI detection process began |
| `analysis_completed` | Detection finished |
| `redaction_approved` | User approved redactions |
| `redaction_completed` | Redaction process finished |
| `document_downloaded` | Redacted file downloaded |
| `document_deleted` | Document removed from system |

### Detection Events

| Action | Description |
|--------|-------------|
| `pii_detected` | PII found in document |
| `phi_detected` | PHI found in document |
| `financial_detected` | Financial data found |
| `custom_pattern_detected` | Custom pattern matched |
| `detection_reviewed` | User reviewed detection |
| `detection_approved` | Detection approved for redaction |
| `detection_rejected` | Detection rejected (false positive) |

### System Events

| Action | Description |
|--------|-------------|
| `api_key_used` | API request authenticated |
| `webhook_triggered` | Webhook notification sent |
| `error_occurred` | Processing error |
| `retry_attempted` | Automatic retry of failed operation |

## Accessing Audit Trails

### Via SDK

```typescript
// Get audit trail for a specific document
const document = await nvisy.documents.get('doc_abc123');

console.log('Audit Trail:');
document.auditTrail.forEach(entry => {
  console.log(`[${entry.timestamp}] ${entry.action}`);
  console.log(`  User: ${entry.user.email}`);
  console.log(`  Details:`, entry.details);
});
```

### Via API

```bash
curl https://api.nvisy.com/v1/documents/doc_abc123/audit-trail \
  -H "Authorization: Bearer $NVISY_API_KEY"
```

### Filtering Audit Logs

```typescript
const auditLogs = await nvisy.auditLogs.list({
  documentId: 'doc_abc123',
  actions: ['redaction_completed', 'document_downloaded'],
  userId: 'user_123',
  startDate: '2024-01-01',
  endDate: '2024-01-31',
  limit: 100
});
```

## Retention Policies

Configure how long audit trails are retained:

```typescript
const policy = await nvisy.retentionPolicies.create({
  auditTrails: {
    retention: '7-years',     // Keep for 7 years (HIPAA requirement)
    archiveAfter: '1-year',   // Archive after 1 year
    deleteAfter: '7-years'    // Delete after 7 years
  },
  documents: {
    retention: '30-days',     // Keep documents for 30 days
    deleteAfter: '30-days'    // Auto-delete after 30 days
  }
});
```

### Common Retention Requirements

| Regulation | Minimum Retention |
|------------|------------------|
| HIPAA | 6 years |
| GDPR | Varies by purpose |
| SOC 2 | 1 year minimum |
| PCI-DSS | 1 year |

## Immutability

Audit trails are immutable and tamper-proof:

- **Write-once** - Entries cannot be modified after creation
- **Cryptographically signed** - Each entry includes a signature
- **Chain verification** - Entries are linked to prevent tampering
- **Third-party verification** - Export for external audit

### Verification

Verify audit trail integrity:

```typescript
const verification = await nvisy.auditLogs.verify('doc_abc123');

if (verification.valid) {
  console.log('✓ Audit trail is valid and unmodified');
} else {
  console.error('✗ Audit trail integrity compromised!');
  console.error('Details:', verification.errors);
}
```

## Export Options

Export audit trails in multiple formats:


## API Integration

### Complete Example

```typescript
import { NvisyClient } from '@nvisy/sdk';

async function auditWorkflow() {
  const nvisy = new NvisyClient({
    apiKey: process.env.NVISY_API_KEY
  });

  // Redact document
  const result = await nvisy.documents.redact({
    file: './document.pdf',
    detectionTypes: ['pii', 'phi']
  });

  // Access audit trail
  console.log('=== Audit Trail ===');
  result.auditTrail.forEach((entry, i) => {
    console.log(`\n${i + 1}. ${entry.action}`);
    console.log(`   Time: ${entry.timestamp}`);
    console.log(`   User: ${entry.user.email}`);
    if (entry.details) {
      console.log(`   Details:`, JSON.stringify(entry.details, null, 2));
    }
  });

  // Generate compliance report
  const report = await nvisy.reports.generate({
    documentId: result.documentId,
    type: 'audit-trail',
    format: 'pdf'
  });

  await report.download('./audit-report.pdf');
  console.log('\n✓ Audit report generated');

  // Verify integrity
  const verification = await nvisy.auditLogs.verify(result.documentId);
  console.log(`\nAudit trail valid: ${verification.valid}`);
}

auditWorkflow();
```
