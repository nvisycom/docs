## Overview

## Format-Specific Features

### PDF Handling

```typescript
const result = await nvisy.documents.redact({
  file: './document.pdf',
  pdfOptions: {
    ocrScannedPages: true,      // Apply OCR to scanned pages
    preserveHyperlinks: true,   // Keep clickable links
    flattenForms: false,        // Keep form fields editable
    removeMetadata: true        // Strip document metadata
  }
});
```

### Excel Handling

```typescript
const result = await nvisy.documents.redact({
  file: './spreadsheet.xlsx',
  excelOptions: {
    processHiddenSheets: true,  // Include hidden sheets
    processFormulas: true,      // Detect in formula values
    preserveFormatting: true,   // Keep cell formatting
    redactComments: true        // Process cell comments
  }
});
```

### Image OCR

```typescript
const result = await nvisy.documents.redact({
  file: './scanned.jpg',
  ocrOptions: {
    language: 'eng',            // OCR language (eng, spa, fra, etc.)
    dpi: 300,                   // Image DPI for processing
    preprocess: true,           // Image enhancement
    orientation: 'auto'         // Auto-detect orientation
  }
});
```

## File Size Limits

<Note>
  File size limits depend on your deployment configuration and plan.
</Note>

### Default Limits

| Format Type | Max Size | Notes |
|------------|----------|-------|
| PDF | 100 MB | Larger files available on request |
| Office Documents | 50 MB | Per file |
| Images | 25 MB | Per image |
| Archives | 200 MB | Uncompressed size |
| Text Files | 10 MB | Per file |

### Large File Handling

For files exceeding limits:
- **Streaming upload** - Process without loading entirely into memory
- **Chunked processing** - Split large files automatically
- **Batch processing** - Handle multiple files efficiently

```typescript
const result = await nvisy.documents.redact({
  file: createReadStream('./large-file.pdf'),
  streaming: true,
  chunkSize: 10 * 1024 * 1024  // 10MB chunks
});
```

## Format Detection

Nvisy automatically detects file formats:

```typescript
// Format is detected automatically
const result = await nvisy.documents.redact({
  file: './document',  // No extension needed
  detectionTypes: ['pii']
});

console.log(result.format);  // 'application/pdf'
```

### MIME Type Support

Supported MIME types:
- `application/pdf`
- `application/msword`
- `application/vnd.openxmlformats-officedocument.*`
- `application/vnd.oasis.opendocument.*`
- `image/jpeg`, `image/png`, `image/tiff`
- `text/plain`, `text/html`, `text/csv`
- `message/rfc822` (email)

## Format Conversion

Convert between formats during redaction:

```typescript
const result = await nvisy.documents.redact({
  file: './document.docx',
  detectionTypes: ['pii'],
  outputFormat: 'pdf'  // Convert to PDF after redaction
});
```

**Supported conversions**:
- Office formats → PDF
- Images → PDF
- Text formats → PDF
- HTML → PDF

## Best Practices

### Choosing Formats

1. **PDF** - Best for sharing redacted documents (universal compatibility)
2. **Office formats** - Use when further editing is needed
3. **Images** - Only for scanned documents requiring OCR
4. **Text** - For simple, unformatted documents

### Optimization Tips

- **Compress PDFs** before upload to reduce processing time
- **Remove unnecessary pages** before processing
- **Use text-based PDFs** instead of scanned when possible
- **Split large documents** into smaller files for faster processing

### Format Limitations

<Warning>
  Some format-specific features may not be preserved:
  - Embedded videos/audio
  - 3D objects
  - Advanced animations
  - Executable macros
  - Digital signatures (removed for security)
</Warning>
