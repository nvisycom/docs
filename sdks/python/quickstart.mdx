<Warning>
  The Python SDK is in early development and has not been updated for the
  current API revision. It provides a configured HTTP client with
  authentication, retries, and error handling — there are no typed service
  methods, so every request is made by passing a raw path. Verify paths against
  the [API Reference](/api-reference/introduction). For full, typed API
  coverage today, use the [TypeScript SDK](/sdks/typescript/quickstart).
</Warning>

## Installation

```bash
pip install nvisy-sdk
```

## Requirements

- Python 3.8 or later
- An API token from your account settings

## Your First Request

```python
from nvisy import Client

client = Client({"api_key": "your-api-token"})

response = client.get_sync("/health")
print(response)
```

## Configuration

```python
client = Client({
    "api_key": "your-api-token",          # Required
    "base_url": "https://api.nvisy.com",  # Optional
    "timeout": 30.0,                       # Optional: 1.0-300.0 seconds
    "max_retries": 3,                      # Optional: 0-5 attempts
    "user_agent": "MyApp/1.0.0",          # Optional
})
```

You can also build a client from the environment:

```python
client = Client.from_environment()
```

Or use the builder:

```python
client = (
    Client.builder()
    .with_api_key("your-api-token")
    .with_timeout(60.0)
    .build()
)
```
